# AI bubble / generic design adversarial audit
Use after creating a substantial UI. These are diagnostic signals, not universal bans.

## Detect pattern clusters
- Centre-aligned oversized hero headline and vague supporting copy.
- Generic gradient/blur/glow used as the primary personality.
- Endless rounded cards, uniform 3-column feature rows and unrelated icon badges.
- Alternating image-left/text-right sections repeating mechanically.
- Identical spacing and symmetry regardless of section purpose.
- Default sans typography with no deliberate typographic hierarchy.
- Template copy: 'Elevate your experience', 'Unlock potential', 'Seamless solutions' and other empty claims.
- Scroll reveals or parallax on every block for no communicative reason.
- Fake testimonials, invented metrics, placeholder logos or fabricated stock.
- A visually dramatic hero that hides navigation, value or shopping actions.

## Review tests
**Logo removal:** Does the visual voice survive without a logo?
**Swap test:** Can an unrelated brand use the same site without material changes? If yes, investigate generic design.
**Silhouette test:** Do sections repeat the same visual geometry?
**Rationale test:** Can each major treatment be justified through project content?
**Source-distance test:** Does the design replicate a consulted reference's signature layout sequence or brand codes?
**Commerce test:** Can shoppers still find variants, prices, stock, policies and checkout?

## Scoring rubric (human/AI judgement, not proof)
Score 0–4 for project specificity, compositional intentionality, typographic art direction, imagery/graphic originality, communication clarity, source distance, usability and technical quality.
0 = failing; 1 = weak; 2 = adequate; 3 = strong; 4 = outstanding with evidence.
Treat scores below 2 as revision targets. Never average away an accessibility or copying concern. Do not pretend the score is an empirical originality detector.

## Revision protocol
Identify the *cause*, not just the symptom. Replace generic information architecture, visual rhythm or concept where needed; cosmetic recolouring is insufficient. Re-check after changes. See [validation](16-validation-protocol.md).
