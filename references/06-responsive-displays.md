# Responsive and display fidelity
Design to available CSS viewport, not guessed screen diagonal or physical resolution. Test representative narrow, portrait, landscape, tablet, desktop, ultrawide and native 4K viewport widths. Distinguish CSS pixels, display pixel ratio and zoom. Provide responsive image sizes via srcset/sizes and art-directed crops via picture where necessary. Make 2x/3x imagery sharp without forcing full-resolution downloads everywhere. Use container queries when components depend on local width. Respect touch, pointer, keyboard, reduced motion, contrast preferences and zoom/reflow. Do not assume OLED detection: support intentional light, dark and optional true-black themes with contrast-safe surface hierarchy. Preserve sRGB fallbacks for wide-gamut enhancements.
