# Reference ethics and anti-cloning
A reference is evidence of a design principle, not a component kit.

## Do
- Extract hierarchy, contrast, pacing, spacing, framing, typographic roles, product discovery strategy and functional patterns in abstract form.
- Separate common functional conventions from distinctive identity/trade dress.
- Credit source URLs in internal design notes where relevant.
- Transform the principle through the new project's content and constraints.
- Build original copy, graphics and layouts; use properly licensed assets.

## Never
- Reproduce distinctive logos, illustrations, photography or slogans.
- Copy the source's recognisable layout sequence or signature visual system.
- Closely imitate another site's entire colour-type-image-motion combination.
- Treat a gallery screenshot as proof of accessibility, responsive performance or code quality.
- Use protected media as placeholders in a deliverable unless authorised.

## Similarity challenge
Compare the candidate against the source at three levels: individual assets, overall composition, and distinctive combinations of elements. If a neutral observer would likely recognise a particular reference before recognising the client's brand, revise substantially. No checklist can legally certify originality; escalate genuinely uncertain cases to human review.
