# WebSkills AI

A framework-independent Agent Skill for distinctive, accessible, commercially effective web design and development.

**Purpose:** guide an existing coding assistant using graphic design, communication design, user experience and engineering standards. No project-specific theme, framework, agent service or external model required.

## Installation
Place this repository's skill directory in a supported skill location (for example `.agents/skills/webskills-ai`, `.claude/skills/webskills-ai`, or `.github/skills/webskills-ai`, depending on the tool). Check the relevant assistant's current skill installation instructions. The root `SKILL.md` is the entry point.

## Versions
- V1: foundation, instruction routing and standards references.
- V2: creative-director review, deliberate reference diversity, anti-cloning safeguards and self-audits.

## Principles
Design for the actual project. Draw lessons from sources, not layouts or identities. Preserve accessibility and purchase usability. Verify technical and visual claims using available tooling; report what was not tested.
