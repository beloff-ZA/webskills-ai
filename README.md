# WebSkills AI

A universal, framework-independent Agent Skill for distinctive graphic design, communication, user experience and web development, with e-commerce emphasis.

**No preset aesthetic. No reference-site cloning. No independent AI system.**

## V1 and V2
- **V1 (foundation):** `SKILL.md`, ten standards references and repository structure.
- **V2 (creative oversight):** deliberate research diversity, source ethics, creative-director adversarial review, an anti-AI-pattern rubric, validation protocol and an optional text-only heuristic audit.

## Installation
Install the repository as a skill folder where your assistant supports the Agent Skills convention, ensuring its root `SKILL.md` is discovered. Typical locations vary by environment, for example `.agents/skills/webskills-ai`, `.claude/skills/webskills-ai` or `.github/skills/webskills-ai`. Refer to your assistant's current documentation. You can also copy the files into a user-level skills directory where supported.

## Workflow
Read the core `SKILL.md`; its links route to detailed references only when needed. Research sources are optional and do not convey licence to copy anything. Design and development are reviewed critically, including the risk of generic AI patterns and reference-derived near clones.

## Quality claims
An AI self-review is **not a plagiarism certificate**. The optional Python audit flags simplistic text/style warning signals only. Real visual similarity, accessibility, performance, UX and responsive testing require human judgement and appropriate browser/device tooling. The skill instructs the coding assistant to report what it actually verified.

## Structure
- `SKILL.md` — entry point and workflow.
- `references/` — universal design, communication, commerce, engineering, inspiration and critique instructions.
- `assets/` — neutral optional assets, not a template collection.
- `scripts/` — optional diagnostics, never assumed executed.
- `evals/` — cross-industry evaluation cases.

## Usage philosophy
A memorable site should be a consequence of meaningful content and deliberate visual communication. It should not be a performance of whatever the internet currently calls 'premium'.
